# Hinglish Sarcasm Detection

A machine learning system for detecting sarcasm in Hinglish (Hindi-English code-mixed) text using traditional NLP techniques and machine learning classifiers.

## 🚀 Features

- Text preprocessing for code-mixed content
- Custom feature engineering (punctuation, emoticons, n-grams)
- TF-IDF vectorization with character/word n-grams
- SVM and Random Forest classifiers
- Class imbalance handling with SMOTE
- Comprehensive model evaluation
