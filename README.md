# Hinglish Sarcasm Detection Toolkit 🔍🤖

A comprehensive repository for detecting sarcasm in Hinglish tweets using traditional ML and deep learning approaches.


## Features ✨
- 5 Different Modeling Approaches
- Preprocessing Pipelines for Hinglish Text
- Extensive Evaluation Metrics
- Hyperparameter Tuning Configurations
- Pretrained Models for Quick Inference

## Models Implemented 🧠
| Model Type | Architecture |
|------------|--------------|
| Traditional ML | Random Forest |
| Traditional ML | SVM (RBF Kernel) |
| Deep Learning | Bi-LSTM with Attention |
| Deep Learning | Bi-GRU |
| Transformer | DistilBERT Fine-tuning |
